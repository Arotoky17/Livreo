# Interface Livreo

Application React, Vite, Tailwind CSS et Leaflet.

- `src/pages/` : écrans par rôle.
- `src/components/` : navigation, profil, livraison et éléments communs.
- `src/styles/` : feuilles CSS regroupées.
- `src/hooks/` : chargement des données et géolocalisation.
- `src/utils/` : calculs et règles métier.
- `tests/` : vérifications automatisées.

Commandes : `npm.cmd run dev`, `npm.cmd run build`, `npm.cmd run lint` et `npm.cmd test`.

Guide complet : [README.md](../README.md).
