# Serveur Livreo

API Express, Prisma et PostgreSQL.

- `server.js` : démarrage.
- `src/config/` : configuration et connexion PostgreSQL.
- `src/controllers/` : traitement des requêtes.
- `src/middlewares/` : authentification, rôles et erreurs.
- `src/routes/` : adresses de l’API.
- `src/services/` : codes de suivi et photos.
- `prisma/` : modèle de données et initialisation.
- `storage/profile-photos/` : photos privées à sauvegarder.
- `tests/` : tests et images dédiées.

Commandes : `npm.cmd run dev`, `npm.cmd start` et `npm.cmd test`.
